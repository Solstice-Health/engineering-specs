# Plans

One file per plan, spike brief, or experiment brief, copied from [`templates/`](../templates/), named `SOL-XXXX-short-slug.md`, reviewed as a pull request. Merged means Approved. Shipped plans are frozen as point-in-time records; later changes get their own plan.
